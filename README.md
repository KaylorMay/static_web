# 卡塞尔学院｜CASSEL ACADEMY

一个无构建依赖的中文静态学院官网展示页。页面使用原创 HTML、CSS、SVG 和 JavaScript 制作，适合直接部署到 Vercel、GitHub Pages 或其他静态托管服务。

## 本地预览

直接打开 `index.html` 即可预览；也可以在项目目录执行：

```bash
npx serve .
```

## 内容与素材边界

- 页面信息架构参考了公开的 MIT 许可静态企业官网模板，具体来源记录在 `THIRD-PARTY-NOTICES.md`。
- 没有复制源项目品牌、作者、演示文案、社交链接、图片或第三方字体。
- 页面中的徽记、背景、院系设定和中文文案均为本项目原创，使用现代龙族幻想的氛围作为创作参考。
- 本页面为非官方致敬创作，与任何原作权利方无关联；联系表单仅在浏览器内反馈，不会上传数据。

## 部署

项目根目录就是静态输出目录，无需安装依赖或执行构建命令。Vercel 选择 `Other` / `No Build Command` 即可。
