# 卡塞尔学院静态官网设计规格

## 目标

将当前空仓库制作成一个可直接部署的中文企业官网展示类静态网站，品牌名称为“卡塞尔学院 / CASSEL ACADEMY”。网站表达神秘、克制、学术化的学院气质，并通过原创世界观文案和原创 CSS/SVG 视觉元素体现“现代龙族幻想”氛围。

## 来源与商业风险边界

- 页面信息架构参考 `Drip3m/business-landing-template`，来源地址：<https://github.com/Drip3m/business-landing-template>。
- 该项目公开标注为 MIT License；本项目不直接复制其品牌、文案、演示数据、作者信息、社交链接或外部图片。
- 新站点不加载第三方图片、图标字体、商业字体或追踪脚本；图形全部使用本地 CSS 与内联 SVG 制作。
- 保留本项目自己的 MIT `LICENSE` 文件，并在 `THIRD-PARTY-NOTICES.md` 中记录参考来源。
- “龙族”仅作为气质和原创设定参考，不使用原作角色、原文段落、官方 Logo、官方插画或受保护的专有素材。页面明确标注为非官方致敬创作。

## 页面结构

单页静态站点包含以下区块：

1. 固定导航：学院徽记、学院档案、院系体系、校历与入学入口；移动端折叠菜单。
2. Hero：学院名称、原创校训、主 CTA“查阅学院档案”和次 CTA“了解院系”，右侧为原创学院徽记/星轨 SVG。
3. 学院档案：用三个统计指标表达学院规模、研究档案和校区安全等级。
4. 院系体系：执行部、龙文研究院、炼金工坊三张内容卡片。
5. 校历与观测：展示三条原创学院动态，延续档案馆/任务简报语气。
6. 入学 CTA：强调“保持好奇，保持清醒”，引导查看入学说明。
7. 联系区：展示学院联络信息和静态联系表单。表单不发送数据，提交后只在浏览器内显示成功状态。
8. 页脚：原创品牌说明、页面导航、非官方致敬说明和当前年份。

## 视觉系统

- 基底：`#080d14` 深夜蓝黑；表面使用半透明深蓝灰。
- 强调：旧金 `#c6a66a` 作为学院档案和边线色；暗红 `#8e3f45` 作为警戒色；青灰 `#87a6ab` 作为信息色。
- 字体：仅使用系统字体栈，标题优先衬线字体，正文使用系统无衬线字体，避免外部字体授权和加载风险。
- 形态：细边框、编号标签、等宽小字、网格/星轨背景、低强度渐变光晕；避免复制任何现成品牌 Logo。
- 动效：150–300ms 的 hover 与滚动渐入；遵循 `prefers-reduced-motion`。

## 技术与可访问性

- 原生 HTML、CSS、JavaScript，无构建步骤、无运行时依赖，适用于 Vercel 静态托管。
- 使用语义化 heading、`aria-label`、键盘焦点样式、可见表单标签和 `aria-live` 状态提示。
- 主要交互目标不小于 44px，移动端无横向滚动，所有关键内容在无 JavaScript 时仍可阅读。
- 使用 CSS `aspect-ratio`、本地 SVG 和纯 CSS 背景，避免外部请求与布局跳动。

## 验收标准

- 页面标题、导航、页脚和所有可见身份信息均为卡塞尔学院原创内容。
- 不出现 NovaTech、Drip3m、模板作者、模板社交链接、捐赠入口或第三方演示联系方式。
- `index.html` 可直接打开；脚本无控制台错误；移动菜单、平滑跳转、表单反馈和返回顶部按钮可用。
- 在本地 HTTP 服务下返回 200；生产部署 URL 返回 200，页面标题为“卡塞尔学院｜CASSEL ACADEMY”。
- Git 提交清晰；推送到当前 GitHub 远程 `KaylorMay/static_web`；Vercel 部署完成后验证公开访问。
