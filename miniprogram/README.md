# 卡塞尔学院微信小程序

这是卡塞尔学院静态官网的原生微信小程序版本，使用 WXML、WXSS 和 JavaScript 编写，不依赖第三方包或网络接口。

## 在微信开发者工具中预览

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 选择项目根目录 `static_web`，工具会根据根目录的 `project.config.json` 将 `miniprogram/` 识别为小程序根目录。
4. 当前项目配置未填写 AppID，可先使用无 AppID 模式预览；发布前替换为真实 AppID。

## 目录说明

- `app.json`：页面、窗口和 TabBar 配置。
- `data/academy.js`：学院静态内容。
- `components/`：章节标题、档案统计、院系卡片、时间线和按钮组件。
- `pages/`：首页、档案、院系、校历和联系页面。
- `assets/`：本地徽记和星轨 SVG 装饰资源。

联系页表单目前只做本地校验和成功反馈，不会上传或保存数据。
